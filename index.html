An independent reconstruction of Fragile Allegiance

OpenTTD exists. OpenRA exists. So why is there still no OpenFA?

Let’s change that.

Latest public preview 0.495 · Windows + Linux · not a finished product · 13 September 2026

OpenFA is an independent reconstruction of the 1990s strategy game Fragile Allegiance. It recreates asteroid colony management, diplomacy and combat for modern systems, using behaviour documented in the original game.

The reconstruction

Rebuilding the game from original evidence

OpenFA reconstructs behaviour from the original program, game files, saved games and direct comparison with the game in action. Screenshots alone are not treated as proof.

OpenFA is

  • An independent reconstruction of the original game
  • A modern engine that runs on current systems
  • Uses assets from a legally installed copy of the original game
  • A base for preserving the original game and adding optional extensions
  • A clear distinction between what is recovered and what is still uncertain

OpenFA is not

  • A visual remake with invented rules
  • A redistribution of the original game or its assets
  • A fork of OpenTTD or OpenRA
  • An official product
  • A finished product
openFA content package .ofapkg modular · no executable plug-ins

Content and extension packages

One format for content, mods and extensions

An .ofapkg can add or change parts of the game without rewriting the engine itself. This lets OpenFA keep a faithful version of the original game while also supporting optional extensions.

New contentBuildings, ships, missiles, ores, research, trade, personnel and scenarios.

Interface and visualsAnimations, HUD elements, extra on-screen information, status indicators and other presentation changes.

New rules and featuresPackages can use features provided by the engine and combine them into new gameplay elements.

The original stays separateThe standard game keeps Fragile Allegiance content and behaviour, while extra ideas can be enabled separately.

Packages already cover far more than the construction catalogue: new missiles, rare asteroid types, extra surface information, visual effects and industry systems are all possible. This is the format intended for OpenFA mods and optional extensions.

Reconstruction principles

How we keep OpenFA faithful to the original

  1. 01Check how the original behavesWe use the program, data files, saved games and recordings of the original in action.
  2. 02Do not fake the resultWhat appears on screen comes from the real game state, not a prepared animation.
  3. 03Compare the lookLayout, colours, layers and draw order are checked against the original.
  4. 04Do not hide guessesIf something is not known yet, it stays clearly marked as uncertain.

How the work gets done

How AI and automation are used

AI helps search the decompilation; tests replay known cases. Original data remains the reference.

01 / Analysis

Using AI to navigate decompiled code

AI helps find connections in the decompiled program and large amounts of game data. Important conclusions still have to be confirmed by the original game or repeatable tests.

02 / Verification

Automated regression tests

Automated tests check saved games, gameplay systems, graphics and repeatable situations taken from the original.

03 / Accountability

Manual review of names and visual fidelity

Names and fidelity claims are reviewed manually. Visual changes are compared in the target client.

Questions from the sector

Frequently asked questions

Can I play OpenFA today?

Yes, but only as a public preview. It is not a finished product and incomplete systems may fail. A local installation of the original Fragile Allegiance is required. Current builds are available from the openFA preview releases.

Will I need the original game?

Yes. OpenFA imports required data from a legal installation of Fragile Allegiance. It does not download or redistribute the original game assets.

Is OpenFA a remake or a source port?

It is an independent reconstruction. The original source code is not available.

What systems are available?

Public preview builds are currently published for Windows x64 and Linux. Both remain development builds rather than supported final releases.

How closely will it match the original?

The goal is to match presentation and behaviour. Extensions stay in separate packages.

Will OpenFA support mods?

Yes. .ofapkg packages can add buildings, ships, missiles, scenarios, interface changes and new features supported by the engine. The standard Fragile Allegiance experience can remain untouched.

Is OpenFA developed with AI?

Yes. AI helps analyse decompiled code and correlate data. Findings still require original sources or reproducible tests.

Why does development progress in bursts?

It is a spare-time project, developed mainly in summer. There is no release schedule.

When will the source code be published?

No date yet. The source link will appear here when the repository opens.
