OpenFA is an independent reconstruction of the 1990s strategy game Fragile Allegiance. It recreates asteroid colony management, diplomacy and combat for modern systems, using behaviour documented in the original game.

The reconstruction

Rebuilding the game from original evidence

OpenFA reconstructs behaviour from the executable, original assets, saved games and runtime observations. Screenshots alone are not treated as proof.

OpenFA is

  • An independent reconstruction of the original game
  • A portable engine with deterministic simulation
  • A legal-installation importer for original data
  • A base for preservation and data-driven extensions
  • Explicitly documented unknowns

OpenFA is not

  • A visual remake with invented rules
  • A redistribution of the original game or its assets
  • A fork of OpenTTD or OpenRA
  • An official product
  • A finished, downloadable game at this stage
FA content package .fapkg data only · versioned · deterministic

Content packages

A controlled format for extensions

A .fapkg is a versioned, data-only ZIP archive. Packages cannot inject executable simulation code.

Safe boundariesTyped data only; no executable plug-ins.

Reproducible compositionStable IDs and priorities make package composition reproducible.

Legacy fidelity protectedOriginal saves use the standard compatibility package.

Version 1 supports construction catalogues. More resource types can be added later.

How the work gets done

How AI and automation are used

AI helps search the decompilation; tests replay known cases. Original data remains the reference.

01 / Analysis

Using AI to navigate decompiled code

AI links functions, data structures, assets and saved state. Its suggestions are treated as hypotheses.

02 / Verification

Automated regression tests

Automated tests cover parsers, saves, simulation, asset decoding and reference actions.

03 / Accountability

Manual review of names and visual fidelity

Names and fidelity claims are reviewed manually. Visual changes are compared in the target client.

Questions from the sector

Frequently asked questions

Can I play OpenFA today?

No public build yet. Development builds run in the target client.

Will I need the original game?

Yes. OpenFA imports required data from a legal installation of Fragile Allegiance. It does not download or redistribute the original game assets.

Is OpenFA a remake or a source port?

It is an independent reconstruction. The original source code is not available.

What systems are planned?

Modern desktop systems are planned. Platforms will be listed after runtime testing.

How closely will it match the original?

The goal is to match presentation and behaviour. Extensions stay in separate packages.

Will OpenFA support mods?

Yes. The .fapkg format contains versioned data only. Version 1 supports construction catalogues.

Is OpenFA developed with AI?

Yes. AI helps analyse decompiled code and correlate data. Findings still require original sources or reproducible tests.

Why does development progress in bursts?

It is a spare-time project, developed mainly in summer. There is no release schedule.

When will the source code be published?

No date yet. The source link will appear here when the repository opens.
