# OpenFA project site

Public project documentation and development journal for OpenFA, an
independent reconstruction of *Fragile Allegiance*.

## Content policy

- Original-game screenshots and decoded research images are clearly labelled
  and used only for identification, commentary and visual comparison.
- The repository does not contain the original game data required to run
  OpenFA.

## Branch naming

Use `docs/update-YYYYMMDD` for GitHub Pages updates. The date is when work on
the update began; later follow-up changes stay on the same branch until merge.

## 3D model gallery

The English and Polish home pages link to the [OpenFA asset catalogue](https://ender-dev-pl.github.io/openfa-assets/index.html#type=buildings), published from openfa-assets. The catalogue includes building studies across seven cultures and refined Terran variants, with editable Blend files, standalone GLB files, views, animations and provenance. These are authored interpretations, not recovered original meshes or gameplay sprites.
